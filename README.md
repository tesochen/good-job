# Good Job! 九大研究任務入口

依 Good Job! 1C 桌機／1F 手機定稿視覺與已確認任務配置製作。純靜態 HTML、CSS、JavaScript；所有路徑支援 GitHub Pages 子目錄。

## 發布

GitHub Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save。

## 內容

- 九大任務、成果篩選、必備来源與建議助手路線。
- 九份 HTML 使用說明及九份教學簡報（v1.0-draft，待正式課堂驗收）。
- 前八個使用者提供的 Notebook 連結；第九個待補。Notebook 來源、版本與複製權限未經驗證。
- 第八個 Notebook 維持單一入口，案例報告 C01／QCC Q01 分流。

本網站不修改 Notebook、不代管研究資料、不提供研究全文。助手母庫目前 01–10 為 v2.1 候選版，R00／C01／Q01 為 v1.0 候選版；不能視為 Notebook 內已安裝版本。

## 更新

Notebook 連結與任務配置由 `tasks.json` 維護；同步更新 `task-data.js` 供免伺服器與本機使用。未驗證權限時不可標示「可複製」或「已就位」。

保留定稿大字、黑白紅配色、手繪主視覺與桌機卡片／手機清單。移除研究範例資料、六階段專案工作台、匯入備份、站內品質／證據／風險／交付操作與助手已安裝宣稱。實際研究操作在 Gemini Notebook 完成。
